当前识别规则

用结构特征判断文件类型，不把未识别的文件误判为支持格式。

必须为合法 JSON 对象，并至少包含 segments_revolver 或 segments_shotgun 数组。每个分段需有 maxDist，以及 flySpeed 数组或数值。
当前阶段是“识别 + 可视化 + 导出原始 JSON”。不会自动更改弹速、衰减或其他参数；模型线只用于观察数据趋势。
